# 倉林畳店 HP デザイントークン

トップページ(top.html)で使用しているデザイントークン一覧。

## Colors

| Token | Value | 用途 |
|---|---|---|
| `--sumi` | `#15120d` | 墨黒(ダークセクションの背景) |
| `--sumi-2` | `#211b14` | 墨黒の少し明るいバリエーション(フッター背景) |
| `--sumi-3` | `#332a1e` | 墨黒の枠線・境界線用 |
| `--washi` | `#f2ead9` | 和紙のクリーム(ライトセクション背景/ダーク背景上の文字色) |
| `--washi-2` | `#e8dbbc` | 和紙の少し濃いトーン |
| `--washi-3` | `#d5c39a` | 和紙の枠線・区切り線用 |
| `--vermillion` | `#9c3b26` | 朱色(ハンコ・アクセント・赤文字ラベル) |
| `--vermillion-deep` | `#742a1b` | 朱色のホバー時濃色 |
| `--igusa` | `#4c5a2b` | い草グリーン(電話/お問い合わせボタン・お問い合わせセクション) |
| `--igusa-deep` | `#37411d` | い草グリーンのホバー時濃色 |
| `--gold` | `#a6864f` | 金糸のアクセント(枠線・キャプション・ハイライト) |
| `--ink` | `#15120d` | 本文の濃い文字色 |
| `--ink-70` | `rgba(21,18,13,.72)` | 本文の中間濃度の文字色 |
| `--ink-45` | `rgba(21,18,13,.62)` | 本文の薄めの文字色(キャプション等) |
| `--paper-70` | `rgba(242,234,217,.78)` | ダーク背景上の中間濃度の文字色 |
| `--paper-45` | `rgba(242,234,217,.68)` | ダーク背景上の薄めの文字色 |

> ヒーロー内「信頼」の文字のみ個別指定 `#c9a24a`(経年変化した畳の黄金色)を使用。

## Typography

| Token | Font | 用途 |
|---|---|---|
| `--font-d` | `'Shippori Mincho', serif` | 見出し・タイトル・サブタイトル・赤文字ラベル |
| `--font-b` | `'Zen Kaku Gothic New', sans-serif` | 本文・ボタン・注釈・UI全般 |

Google Fonts 読み込み元:
```
https://fonts.googleapis.com/css2?family=Shippori+Mincho:wght@400;500;600;700;800&family=Zen+Kaku+Gothic+New:wght@300;400;500;700;900&display=swap
```
